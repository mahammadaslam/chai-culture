# ☕ Chai Culture – Premium Indian Chai Website

Chai Culture is a responsive, multi-page website designed for a premium Indian chai brand.  
The project focuses on clean UI, strong visual storytelling, and structured layout using **HTML and CSS** only.

🔗 **Live Demo:**  
https://<your-github-username>.github.io/chai-culture/

---

## 📌 Project Overview

This website represents a fictional premium chai brand rooted in Indian heritage.  
It highlights brand storytelling, signature chai blends, and a modern yet warm user experience.

The project was developed as part of an assignment to demonstrate:
- Frontend fundamentals
- Layout structuring
- Visual design sense
- Real-world project organization

---

## 🧩 Pages Included

- **Home Page**
  - Full-width hero image
  - Brand introduction
  - Call-to-action
  - Core brand values

- **Shop Page**
  - Signature chai blends
  - Product cards with images, descriptions, and pricing
  - Clean grid layout

- **About Page**
  - Brand story
  - Philosophy and vision

- **Contact Page**
  - Contact information
  - Simple message form

---

## 🛠️ Technologies Used
